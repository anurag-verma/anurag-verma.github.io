## 📌 About This Repo

This repository hosts the source code for my personal portfolio website — a single-page, dependency-free site built with plain **HTML, CSS, and JavaScript**. No frameworks, no build step: open `index.html` and it just works.

It doubles as a sandbox for iterating on design directions before picking a final one — that's why you'll find a few alternate versions alongside the live site.

## 🗂️ Project Structure

```
portfolio/
├── index.html                  # 🟢 Live site — current production version
├── index_v1.html                # Earlier iteration, kept for reference
├── portfolio-premium.html       # Alternate design exploration
├── portfolio-pixohub.html       # Alternate design exploration
├── portfolio-saas.html          # Alternate design exploration
├── assets/
│   ├── hero-developer.json      # Lottie animation used in the hero section
│   └── *-before.png / *-after.png  # Case-study screenshots (site redesigns)
└── .github/                     # Repo configuration
```

## ✨ Highlights of the Site

- **Case-study redesigns** — before/after comparisons for real client rebuilds (Ariston Realty, Kahane Law Office, The Dental Surgeon)
- **Project showcase** — Laravel-built portals, CRMs, and automation tools with live links
- **Smooth micro-interactions** — scroll-progress bar, reveal-on-scroll animations, animated skill marquee
- **Fully responsive** — safe-area aware, mobile-first navigation
- **Zero dependencies** — no `npm install`, no bundler; Google Fonts + a Lottie animation are the only external assets

## ⚙️ CI/CD

Every push and PR to `main` runs an [HTMLHint](https://github.com/htmlhint/htmlhint-action) lint check on `index.html` via GitHub Actions ([`.github/workflows/ci-cd.yml`](.github/workflows/ci-cd.yml)). The site itself is served directly by GitHub Pages from this repo.

## 🚀 Running Locally

No build tools required — just open the file, or serve it for a closer-to-production experience:

```bash
git clone https://github.com/anurag-verma/anurag-verma.github.io.git
cd anurag-verma.github.io

# Option 1: just open it
start index.html      # Windows
open index.html        # macOS

# Option 2: serve it (recommended, avoids some file:// quirks)
npx serve .
```
